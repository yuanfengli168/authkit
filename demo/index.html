⚡ Quick start

import AuthKit from 'https://yuanfengli168.github.io/authkit/index.js' 
import AuthKit from './authkit/index.js';

await AuthKit.init({
  firebase: firebaseConfig,
  enabledProviders: ['google', 'email'],
  anchor: '#auth-anchor',
  loginMode: 'inline',   // or 'modal'
  theme: 'auto',
  brandName: 'My App',
  settings: {
    enableSavedKeys: true,
  },
});

AuthKit.onAuthStateChanged((user) => {
  if (user) console.log('Signed in:', user.email);
});

🚀 How to use

  • 1
    Clone or copy the authkit/ folder into your project
  • 2
    Add your Firebase config and call AuthKit.init()
  • 3
    Drop <div id="auth-anchor"></div> anywhere on the page
  • 4
    Enable Google auth & Email/Password in Firebase Console
  • 5
    Deploy your firestore.rules — done!

📋 What's included

Core: session manager, pub/sub state machine, provider registry, Firestore wrapper.

Providers: Google OAuth (popup/redirect, link/unlink) · Email/password (sign in, sign up, reset).

UI: Modal & inline variants · Settings page (profile, connected accounts, saved keys, danger zone) · Full ARIA + focus trap.
